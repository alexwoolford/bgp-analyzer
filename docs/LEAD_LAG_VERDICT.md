# Evaluation headline

Offline evaluation found **BGP network-contact alone is a weak M&A predictor**. Treating high `score` values as deal leads does not clear a practical precision bar.

This product still ships a useful **attributable network-contact feed** (ASN / org / domain). Use `score` for triage only—not as P(deal)—and do not rank BGP-first for M&A discovery. PeeringDB `orgs` rows are a join spine, not deal events ([ORG_MAP.md](ORG_MAP.md)).
